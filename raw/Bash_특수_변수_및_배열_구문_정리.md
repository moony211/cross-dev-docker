# Bash 특수 변수 및 배열 구문 정리

`scripts/build-and-push-images.sh` 스크립트에서 사용된 주요 Bash 특수 변수와 배열 관련 구문에 대한 정리입니다.

## 1. 매개변수 관련 특수 변수

### `$#` (인자의 개수)
- **의미**: 스크립트나 함수에 전달된 **명령줄 인자의 총 개수**를 나타냅니다.
- **스크립트 내 활용**: `if [[ $# -gt 0 ]]; then` 문에서 사용자가 특정 빌드 타겟을 인자로 전달했는지 확인하는 용도로 사용됩니다.

### `$@` (모든 인자)
- **의미**: 전달된 **모든 인자**를 개별적인 문자열로 나타냅니다.
- **`"$@"` (Double Quotes)**: 인자 값에 공백이 포함되어 있어도 이를 하나의 단위로 유지하며 안전하게 확장합니다. 스크립트 작성 시 `$*`보다 권장되는 방식입니다.
- **스크립트 내 활용**:
    - `for arg in "$@"; do`: 전달된 모든 타겟 인자를 순회합니다.
    - `run()` 함수 내에서 `"$@"`를 호출하여 전달받은 명령어를 그대로 실행합니다.

---

## 2. 배열 관련 구문

### `"${array[@]}"` (배열의 모든 요소)
- **의미**: 배열 내의 **모든 원소**를 개별적으로 확장합니다.
- **스크립트 내 활용**: `for entry in "${build_targets[@]}"; do`와 같이 배열의 각 항목(경로와 이미지 이름 쌍)을 순회할 때 사용됩니다.

### `${#array[@]}` (배열의 크기)
- **의미**: 배열에 담긴 **요소의 총 개수(길이)**를 반환합니다.
- **스크립트 내 활용**: `targets_to_build` 배열이 비어있는지 확인하여, 일치하는 빌드 타겟이 없는 경우 에러를 발생시키는 로직에 사용됩니다.

---

## 3. 기타 문자열 조작 (Parameter Expansion)

스크립트 내에서 경로와 이미지 이름을 분리할 때 사용된 구문들입니다.

- **`${entry%% *}`**: 문자열의 **뒤에서부터** 가장 긴 공백 패턴을 제거합니다. (첫 번째 단어인 '경로'만 추출)
- **`${entry##* }`**: 문자열의 **앞에서부터** 가장 긴 공백 패턴을 제거합니다. (마지막 단어인 '이미지 이름'만 추출)
